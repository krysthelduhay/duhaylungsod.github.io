About:
This is a personal portfolio site with a soft scrapbook / polaroid diary aesthetic — torn-paper textures, tape accents, and handwritten-style typography — built entirely with semantic HTML5 and pure CSS3 (no JavaScript, no frameworks).

Sections:
Header — logo, name, course & year, and personal motto
Navigation — sticky top-right menu linking to each section
Home — welcome message with profile photo
About Me — personal information, educational background (with a table of schools and roles), and career goals
Skills — six skill cards with images and descriptions
Gallery / Portfolio — a grid of project work with captions
Contact — a contact form (name, email, subject, message)
Footer — credits and social links

Built With:
- HTML5 — semantic page structure
- CSS3 — Grid & Flexbox layout, custom properties, transitions
- Google Fonts — Playfair Display, EB Garamond, Caveat
